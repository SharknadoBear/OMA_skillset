# FVCOM River Forcing

Use this skill as an initial FVCOM river-forcing toolbox. It packages existing Delaware-oriented helpers and copied dependencies for completeness; do not treat generated products as scientifically accepted until project-specific river nodes, gauges, timing, and tracer settings are reviewed.

## Core Rules

- Reuse the bundled scripts; write the least new code possible.
- Treat the built-in P0-P7 Delaware cases as ready examples, not a universal river-forcing configuration.
- Keep river/inflow nodes separate from ocean OBC nodes generated by `fvcom-preconfiguration`.
- Preserve positive discharge units and FVCOM time conversion conventions from the scripts.
- Use the copied `microplastic_forcing.py` only for tracer concentration coupling; do not duplicate microplastic formulas elsewhere.

## Bundled Scripts

- `scripts/analytical_river_forcing.py`: Delaware P0-P7 analytical river-forcing builder and CLI.
- `scripts/usgs_rivers_fetcher.py`: USGS NWIS discharge fetch/cache and flow helper functions.
- `scripts/microplastic_forcing.py`: copied microplastic concentration helper used by river forcing.
- `scripts/fvcom_writer.py`: FVCOM river NetCDF and NML writer helpers.
- `scripts/grid_utils.py`: FVCOM time and grid utility helpers.

## Typical Use

Generate selected default-registry cases:

```powershell
python scripts/analytical_river_forcing.py P0 P1 --plastic-source legacy_constant
```

Use `--plastic-source drbc_microfiber` only when the required DRBC workbook and FVCOM-MP plastic config files are available in the expected project layout or are passed through code-level helper calls.

For non-Delaware domains, use the script as a template/library: define the project river names, river nodes, gauge sources, node weights, and tracer scenario before writing FVCOM river files.
