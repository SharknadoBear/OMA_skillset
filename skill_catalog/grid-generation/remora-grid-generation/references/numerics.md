# Numerical conventions

- A local WGS84 transverse Mercator projection is conformal. Densify the four geographic polygon sides, fit an enclosing rotated rectangle, pad it and use this as the seed for the numerical footprint. Keep the original polygon. Supported projected spans remain at most 1500 km, excluding polar/antimeridian geometry. https://proj.org/en/stable/operations/projections/tmerc.html
- New `conformal_graded` geometry applies the dimensionless analytic map `F(z)=z+c2*z^2+c3*z^3` to centered, scaled logical coordinates, then rotates and translates into projected physical coordinates. A global sufficient derivative-perturbation bound `2*abs(c2)*R+3*abs(c3)*R^2 <= 0.45` covers the parameter rectangle and rho halo; it prevents folding within this bounded deformation family. This is a low-order footprint adjustment, not general boundary-conforming meshing.
- Separate monotone PCHIP controls redistribute xi and eta before the analytic map. Controls increase in both columns from `[0,0]` to `[1,1]`; evaluated coordinate derivatives must be positive. Halo continuation is linear at the end derivative. Axis redistribution preserves orthogonal coordinate directions but changes cell sizes across coordinate bands; it does not create local AMR.
- The fit dilates the parameter extent within bounded attempts until the curved physical footprint covers the densified geographic mission plus padding. Added area remains a scientific review decision. Zero conformal coefficients recover a rotated rectangle; identity axis controls retain the ungraded case. Legacy requests still use the original uniform rotated geometry.
- Generate every stagger from the same continuous physical map, then inverse-project. Measure cell-centered dx/dy between symmetric half-cell locations using WGS84 geodesics. pm=1/dx and pn=1/dy. Compute angle from the local xi tangent; do not assume zero on a rotated or curved grid. New geometry checks a positive analytic Jacobian, finite metrics, orthogonality error no larger than 0.05 degrees, positive oriented physical cell area, and the configured maximum neighboring geodesic spacing ratio. Aspect ratio is reported for scientific review. Logical x/y coordinates are not physical mapped positions or true metric spacing.
- A wet candidate is outside shoreline land and has negative positive-up elevation. Minimum-depth clipping never turns a land cell wet. Missing elevation in shoreline water fails coverage. Explicit positive-down source fields are supported, with metadata sign checks.
- Four-neighbor connectivity preserves the component containing all protected wet features; disagreeing features stop the build. With no anchors retain the largest boundary-connected component, or the largest component in a closed domain. Other wet components are recorded as dry edits. Important lagoons and narrow connections must be named before accepting automatic edits.
- Explicit `close_optional` adjustments can only dry selected source-water cells for a named optional region feature and require rationale plus source/finding evidence. Essential anchors are checked after those closures. This is distinct from source-artifact repair, which creates a new source file using independent water evidence and original wet donors while protecting mapped real land. Neither mechanism permits an undocumented wet opening through physical land.
- Smooth natural log depth, never linear depth. Deterministic red/black wet-wet pairs project excessive log jumps onto `log((1+rx0)/(1-rx0))` while preserving the pair's area-weighted log mean. Exponentiate and independently verify rx0, with bounded iteration and explicit nonconvergence. Do not rescale to conserve volume. Report initial/final volumes and fractional change for all rho cells including halo, physical-interior volume change separately, maximum/RMS depth changes, and feature-section area changes. Positive wet depths, positive areas and unchanged masks are mandatory. Log corrections remain within each pair's previous depth bounds. The depth floor only guards floating-point roundoff after exponentiation. This is not a guarantee of pressure-gradient accuracy.
- Reproduce REMORA Vtransform=2 and its theta_s=0, theta_b=0 limits. Diagnose actual layer thickness and the layer-aware Haney rx1 measure from the selected vertical coordinates; it is not the two-depth rx0 ratio. New scientific requests condition and validate against the actual layer-aware rx1 target as well as rx0. Final rx1 must be below the configured hard bound, and preferred attainment is reported separately. Process vertical checks in bounded row blocks with a one-row overlap to preserve every wet-neighbor Haney pair; generate only the plotted vertical sections. This preserves the full-array equations and extrema without retaining domain-wide three-dimensional coordinates. Horizontal grid arrays still scale with domain size.
- REMORA derives staggered masks from mask_rho. Pinned source's psi mask is 1 with three/four wet neighbors, 2 with two adjacent wet neighbors, otherwise 0. It is not a binary four-cell product.
